<objective>
Extend the reporting-unit schema and the shapefile export to carry the full RMA attribute set (ACR-06 / D-18), and give the user an editable per-unit RMA field surface (ACR-05, D-19: RMA unit number is user-entered). The hand-rolled shapefile writer already works and is production-tested — EXTEND its `DBF_FIELDS` array in place; do NOT introduce a new shapefile library (RESEARCH Don't-Hand-Roll).

Purpose: ACR-05 tabular report and ACR-06 output .shp both require fields that don't exist yet: grower/policyholder, share %, RMA unit number, policy number, a genuine prevent-plant vs failed-acre distinction, and the auto/manual/overridden source flag. Because this column arrives in migration 040 but the merge (`merge_reporting_units`) and draw-from-scratch (`insert_manual_clu`) RPCs are defined earlier in migration 038 (plan 72-03) — before the column exists — those functions' INSERTs cannot reference `source_flag` and would leave merged/hand-drawn units at the column default `'auto'`. That defeats D-18/ACR-05 provenance. Migration 040 therefore also CREATE OR REPLACEs both RPCs to stamp `source_flag='manual'` explicitly.
Output: migration 040 (RMA columns + extended export RPC + merge/draw RPCs redefined to set source_flag='manual'), extended DBF export, extended clu-records write route, and RMA edit fields in the CLU Records workspace.
</objective>
