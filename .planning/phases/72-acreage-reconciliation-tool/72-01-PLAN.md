<interfaces>
Threshold semantics to implement (D-11–D-14, from PATTERNS.md Pattern 3):
- Green: absDelta <= max(green_ac, fsaAcres * green_pct/100)  → no flag, auto-finalize permitted
- Yellow: absDelta <= max(yellow_ac, fsaAcres * yellow_pct/100) OR pctDelta in (green_pct, yellow_pct] → review, reportable
- Red: otherwise; ALSO Red if sliver geometry < red_sliver_ac, or planted area outside all CLUs
Default config values (D-11/12/13/14): green_pct=2, green_ac=0.5, yellow_pct=5, yellow_ac=2.0, red_sliver_ac=0.1
Existing status vocabulary in reconciliation.ts / calc.ts is `'ok' | 'flagged' | 'unresolved'` (type ReconciliationStatus). Map green→ok, yellow→flagged, red→unresolved so existing callers/importers keep compiling.
</interfaces>
